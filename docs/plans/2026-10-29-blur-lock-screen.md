# 视频失焦锁屏

参考 PDF 项目最终交互：默认关闭失焦锁屏，密码初始化为空；手动启用后点击时间恢复，设置密码后点击时间展开输入框。

## 实现

1. 在视频根目录（`--dir` 指定目录，默认启动目录）的 `.video/config.json` 初始化 `blurLockScreen: false`、`lockPassword: ""`。保留已有配置、密码和其他字段；无效配置明确报错。
2. 服务端只公开开关、工作区标识、是否需要密码。密码通过服务端校验，不发送给页面。
3. 监听窗口失焦、页面隐藏和离开；同一标签页刷新继续保持锁定。配置尚未加载或加载失败时遮挡页面，提供重试。
4. 使用原生模态 dialog 覆盖普通页面、网页全屏和原生全屏。完整遮住目录和视频，暂停播放，保留视频、进度、原有手动遮挡状态；解锁后恢复锁屏前播放状态。
5. 时间、日历、山水装饰复用当前主题语义变量和 SVG；森林与水墨均保持当前画风。锁屏不显示视频文件名或播放器提示。

## 验证

- 配置创建、补齐、已有值保留、无效配置、密码校验与不泄露。
- 失焦/隐藏、刷新保持、禁用、配置加载竞态、解锁竞态、事件清理。
- 构建、完整测试与浏览器检查森林/水墨、桌面/移动、全屏、暂停/恢复、错误密码与键盘行为。

配置修改在重启服务后生效。此功能是浏览器内容遮挡，保留已有本地视频访问方式。

## 验证结果

- `npm run build` 通过；`npm test` 的 48 项测试全部通过。
- Chrome 实测通过：真实失焦、声音暂停、回到页面保持锁定、空密码点击时间恢复、错误密码拦截、正确密码恢复、同一播放器及进度保留、原先暂停状态保留。
- 同一标签页刷新保持锁定和播放进度；原有手动视频遮挡状态不被锁屏重置。
- 原生全屏和网页全屏遮挡、解锁后全屏保留；森林与水墨的桌面布局、水墨 390px 移动布局和字体/图片切换通过，无水平溢出。
- 配置加载失败时内容保持遮挡，重试可恢复；禁用锁屏时失焦不触发。
- `npm pack --dry-run --ignore-scripts` 确认包含服务端配置模块和前端构建文件，不包含 `.video` 私有配置。
